# API-FOOTBALL v3 contract registry

Canonical offline registry for the 38 football paths plus /status represented by the existing 42 MCP tools. Documentation that cannot be acquired remains PENDING_OFFICIAL_VERIFICATION; this is never PASS. REAL_VERIFIED is forbidden while live authorization is off. No scheduled job is configured.

Generate a deterministic snapshot with scripts/check_api_football_contracts.py --write docs/api_football/snapshots/current.json. A missing official page preserves the last valid snapshot.
